一、电化学基本概念
1. 电化学：研究电能与化学能相互转化的学科，分为原电池（化学能→电能）和电解池（电能→化学能）。
2. 两类核心装置区别：
原电池：自发氧化还原反应，对外输出电能，无需外接电源。
电解池：非自发氧化还原反应，需外接电源输入电能才能进行反应。
3. 电极定义（通用）：
阳极：发生氧化反应（失电子）的电极
阴极：发生还原反应（得电子）的电极
4. 正负极区分：
原电池：正极=阴极（还原）、负极=阳极（氧化）
电解池：正极=阳极（氧化）、负极=阴极（还原）
5. 电解质：水溶液、熔融盐、离子导体，依靠离子定向移动导电；金属依靠自由电子导电。
二、原电池与电池符号
1. 原电池构成条件
自发的氧化还原反应、两个活泼性不同的电极、电解质溶液、闭合回路。
2. 电池书写规则（国际通用）
书写顺序：负极｜负极电解质｜｜正极电解质｜正极
符号说明：
｜ 表示相界面，｜｜ 表示盐桥（消除液接电势）
左侧为负极（氧化），右侧为正极（还原）
溶液标注浓度，气体标注分压，固体、纯液体不标注
3. 经典铜锌原电池（丹聂尔电池）
电池符号：Zn(s)｜ZnSO₄(aq)｜｜CuSO₄(aq)｜Cu(s)
负极反应（氧化）：Zn − 2e⁻ = Zn²⁺
正极反应（还原）：Cu²⁺ + 2e⁻ = Cu
总反应：Zn + Cu²⁺ = Zn²⁺ + Cu
三、电极电势与能斯特方程（核心公式）
1. 标准电极电势 φ⊖
定义：298.15K、标准状态下（离子浓度1mol/L，气体分压100kPa，纯固体纯液体），相对于标准氢电极的电极电势。
标准氢电极：φ⊖(H⁺/H₂)=0.0000V
规律：φ⊖越大，氧化态氧化性越强；φ⊖越小，还原态还原性越强。
2. 能斯特方程（任意温度、浓度/分压）
通用式：$$\varphi = \varphi^\ominus + \frac{RT}{nF}\ln\frac{[氧化态]}{[还原态]}$$
298K简化式（最常用）：$$\varphi = \varphi^\ominus + \frac{0.0592}{n}\lg\frac{[氧化态]}{[还原态]}$$
参数说明：
n：电极反应转移电子数
F：法拉第常数，≈96485 C/mol
R：气体常数，8.314 J/(mol·K)
浓度规则：固体、纯液体活度为1，不写入公式；气体用相对分压
3. 电池电动势计算
标准电动势：E⊖ = φ⊖(正极) − φ⊖(负极)
任意状态电动势：E = φ(正极) − φ(负极)
自发反应判据：E > 0，反应正向自发；E = 0，反应达平衡；E < 0，反应逆向自发
四、电化学与热力学关系（必考公式）
1. 吉布斯自由能变与电动势：$$\Delta_r G_m = -nFE$$
标准状态：$$\Delta_r G_m^\ominus = -nFE^\ominus$$
2. 平衡常数与标准电动势：$$\lg K^\ominus = \frac{nE^\ominus}{0.0592}$$（298K）
3. 反应自发性统一判据：
ΔG < 0、E > 0、K > 1 → 正向自发
ΔG = 0、E = 0、K = 1 → 平衡状态
ΔG > 0、E < 0、K < 1 → 逆向自发
五、常见电极类型
1. 金属-金属离子电极
示例：Zn²⁺/Zn、Cu²⁺/Cu，反应：Mⁿ⁺ + ne⁻ = M
2. 气体-离子电极
示例：氢电极、氯电极，需惰性电极（Pt、石墨）导电
标准氢电极反应：2H⁺ + 2e⁻ = H₂(g)
3. 氧化还原电极（惰性电极）
同一元素高低价离子转化，如Fe³⁺/Fe²⁺、MnO₄⁻/Mn²⁺
示例：Fe³⁺ + e⁻ = Fe²⁺
4. 难溶盐电极
示例：AgCl/Ag 电极，反应：AgCl(s) + e⁻ = Ag(s) + Cl⁻(aq)
六、电解池与电解规律
1. 电解池电极反应规律
阳极（氧化）放电顺序：S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根 > F⁻
阴极（还原）放电顺序：Ag⁺ > Fe³⁺ > Cu²⁺ > H⁺(酸) > Pb²⁺ > Sn²⁺ > Fe²⁺ > Zn²⁺ > H⁺(水) > Al³⁺ > Mg²⁺ > Na⁺
2. 电解核心定律：法拉第电解定律
电极上析出物质的物质的量与通过电解液的总电荷量成正比
公式：$$Q = It,\ \ n = \frac{Q}{nF}$$
七、电极极化与超电势
1. 极化：实际电解过程中，电极电势偏离平衡电势的现象
2. 超电势η：实际电势与平衡电势的差值，η＞0
3. 极化规律：阳极极化电势升高，阴极极化电势降低
4. 极化分类：浓差极化、电化学极化
5. 应用：超电势使H₂、O₂析出电势改变，是电解精炼、电镀的重要原理
八、金属腐蚀与防护
1. 电化学腐蚀（最主要）
原理：金属表面形成微型原电池，活泼金属作负极被氧化腐蚀
析氢腐蚀（酸性环境）：正极2H⁺+2e⁻=H₂↑
吸氧腐蚀（中性/弱碱性环境，最常见）：正极O₂+2H₂O+4e⁻=4OH⁻
2. 金属防护方法
（1）涂层保护：油漆、电镀、钝化
（2）牺牲阳极法（原电池原理）：连接更活泼金属，保护主体金属
（3）外加电流法（电解池原理）：主体金属接电源负极作阴极被保护
九、典型化学电源
1. 干电池（锌锰电池）
负极：Zn 氧化，正极：MnO₂ 还原，一次性电池
2. 铅蓄电池（二次电池）
放电为原电池，充电为电解池，可循环使用
3. 燃料电池
燃料在负极氧化，氧化剂在正极还原，能量转化率高，无污染
十、高频易错总结
1. 电极电势强度只与本性、温度、浓度有关，与电极面积、反应速率无关。
2. 能斯特方程中，纯固体、纯液体不写入浓度项。
3. 电池电动势是强度性质，与反应方程式系数无关；ΔG、K 与系数有关。
4. 原电池盐桥作用：连通回路、消除液接电势、维持溶液电中性。
5. 吸氧腐蚀是钢铁腐蚀的主要形式，中性环境优先发生。
